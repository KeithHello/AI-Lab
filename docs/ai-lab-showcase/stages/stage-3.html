階段定位與目標

一句話定義：具備完整軟體交付能力的初階造物者。能真正打通應用的任督二脈，讓產品不再只是 Demo，而是能存檔、能運作的真實系統。

你在這個階段的畫像

你已經能用 Vibe Coding 做出原型，但想做更複雜的東西；你發現 AI 生成的程式碼有時需要手動調整才能跑；你想讓應用「真的能用」：有登入、能存資料、別人也能訪問。這個階段的目標：掌握全棧開發 + LangChain Agent，獨立交付完整系統。

前置條件與環境排錯

  • ✓
    已完成 Stage 2 與練習 5 技術地基
  • ✓
    能看懂基本 HTML/CSS/JavaScript，有 GitHub 帳號並了解 git
  • ✓
    Python 環境已安裝 (3.10+)
💡 Python 與開發環境排錯檢核表：
- 找不到 python 命令：安裝時勾選 "Add Python to PATH"
- 虛擬環境：專案根目錄 `python -m venv .venv` 並 activate 啟用
- 套件安裝失敗：嘗試 `python -m pip install `
- 金鑰安全：嚴禁 API Key 硬編碼！使用 `.env` 搭配 `python-dotenv`
3

知識點與架構

1. 全棧開發基礎與 AI 輔助心法基礎

技術棧： React / Next.js（前端）、Node.js / Python FastAPI（後端）、Supabase PostgreSQL（資料庫）、Vercel / Render（部署）、Clerk / Supabase Auth（身份驗證）。

AI 輔助心法：先問 AI 設計架構 → 分段實現前端與後端 → 遇到報錯直接貼給 AI 排查 → 理解層級分工即可，無需死背語法。
2. Python + LangChain Agent 開發核心
概念一句話解釋
Chain把多個步驟串聯（A → B → C）
Tool封裝一個能被 Agent 呼叫的函數
AgentExecutor Agent 的執行時：思考→呼叫工具→觀察循環
Memory讓 Agent 記住之前的對話
Runnable / LCELLangChain 的宣告式程式設計介面
Callback在每個節點插入自定義邏輯與日誌

Agent 4 種類型： ReAct（通用推理）、Plan-and-Execute（複雜規劃）、OpenAI Functions（原生 Tool）、Structured Chat（多參數工具）。

技能要求與推薦工具

🛠️ 硬技能

Python 基礎、LangChain (Chain/Tool/AgentExecutor/Memory)、FastAPI/Node.js REST API、SQL (CRUD)、Git 操作、Docker 基礎、.env 環境變數管理。

💡 軟技能

問題分解（大需求拆小步驟）、錯誤排查（系統性看報錯）、技術選型（知道何時用哪種技術棧）。

5

實作練習與大型專案

練習 0：Python Function Calling 程式碼過渡基礎
用 `openai.OpenAI()` 寫 Python 腳本，呼叫含 `tools` 的 API 並印出 `tool_calls`。
練習 1：Hello Agent（1 小時）LangChain
用 LangChain 建立第一個帶 `calculator` 工具的 Agent 並計算圓面積。
練習 2：寫 3 個自定義 Tool（2 小時）自地
建立查天氣、查翻譯、讀本地檔案三個 Tool，讓 Agent 按需呼叫。
練習 3：ReAct 循環 Tracing（1.5 小時）Tracing
為 Agent 加上詳細 Logging，把思考、工具呼叫、觀察過程整理成 Markdown。
練習 4（專案 A）：AI 程式碼助手 Agent（4 小時）專案 A
工具集：read_file, search_code, run_shell, explain_code。完成端點清單提取、SQL injection 風險檢查與依賴分析。
練習 5（專案 B）：AI 增強型筆記應用（8 小時）專案 B
Next.js + FastAPI + Supabase + LangChain。含 Google Auth、筆記 Markdown CRUD、選中文字 AI 助理分析卡片。
