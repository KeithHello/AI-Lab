階段定位與核心思維轉變

一句話定義：不再只是「設計 Agent」，而是設計「能設計 Agent 的 Agent」（Meta-Agent）。你打造的系統具備自我反思、自我評估、自我改進的能力，可在無人工干預下持續進化。
思維轉變：
- Stage 5（傳統）：人類工程師 → 設計 Prompt → 選擇工具 → 配置評估 → 人類調優
- Stage 6（進化）：Meta-Agent → 自動設計子 Agent → 自動評估 → 自我修正 Prompt/Tool
2

前置條件

A軌：完成 Stage 5 A軌，至少 1 套 Multi-Agent 系統在生產環境運行，掌握 LangSmith/LangFuse 評測。
B軌：完成 Stage 5 B軌，至少 1 套 Dify/n8n 系統在生產運行，有日誌追蹤與手動評測經驗。

3

6 大自我進化能力

能力 1–3：自我評估、工具生成與動態 Prompt核心
  • 🔄
    能力 1 自我評估 (Reflexion)：執行任務 → 評估結果 → 診斷失敗原因 → 產生經驗教訓 (Lesson) 存入長期記憶。
  • 🛠️
    能力 2 自主工具生成 (Tool Generator)：發現缺工具 → 自動編寫 Python 程式碼 → 產生 Description → 驗證測試 → 加入工具庫。
  • ⚡
    能力 3 動態 Prompt 編譯 (DSPy / LLM-as-a-Judge)： [A軌] 使用 DSPy 自動搜尋最優 Prompt；[B軌] 建立批次評測 Dataset 與 LLM-as-a-Judge 自動淘汰低效 Prompt。
能力 4–6：RL 微調、元 Agent 與持續學習進階
  • 📈
    能力 4 強化學習與微調 (GRPO / DPO)： GRPO（組內相對比較，無 Critic 模型，DeepSeek-R1 核心技術）；個人建議在 Colab 上用 Unsloth / Llama-Factory 微調。
  • 🤖
    能力 5 元 Agent 架構 (Meta-Agent)： Designer（設計器）、Evaluator（評估器）、Optimizer（優化器）三大元角色。
  • 🛡️
    能力 6 持續學習管道：經驗回放、課程學習、災難性遺忘防護、人機回環 (Human-in-the-Loop 安全閘門)。
S5 vs S6 企業價值對比對比
維度傳統 Agent (Stage 5)自我進化 Agent (Stage 6)
維護成本工程師定期手動調整 Prompt與工具Agent 自我調整，維護成本趨近於零
適應速度業務變化 → 等待開發排程業務變化 → Agent 即時自我適應
錯誤改進依賴人工發現修復Agent 自動發現並自動修正
