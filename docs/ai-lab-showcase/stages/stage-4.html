🔗 Stage 4：流程自動化專家

打破軟體孤島，打造全自動流程

2-3 週建議學習時間
Phase 4：流程自動化對應路線階段
手機版網頁完整預覽（無 .md 連結）
1

階段定位與目標

一句話定義：企業數位轉型的核心推手。不迷信單一軟體，而是專精於打破「軟體孤島」，將企業碎片化的工具串聯成「免人工干預」的完全自動化流程。

你在這個階段的畫像

你發現許多企業的問題不是「缺軟體」，而是「軟體之間不溝通」；你在企業內部看到大量重複的人工作業（複製貼上、Excel 報表、Email 通知）。這個階段的目標：讓流程跑得比人快、比人準、而且 24 小時不休息。

2

  • ✓

  • ✓
    理解 API 是什麼（會看文件、知道呼叫方式）
  • ✓
    知道 JSON 格式並能看懂基本結構
3

知識點與架構

1. 自動化思維與 6 步設計流程思維

判斷標準（值得自動化）：高頻（每天/每週）、規則明確、重複性高、人為出錯代價高、ROI 符合預估。

6 步設計： 1. 觀察 ──→ 2. 記錄 ──→ 3. 拆解 ──→ 4. 建構 ──→ 5. 測試 ──→ 6. 監控。

2. 工具與技術要點技術
工具說明技術要點
Make.comSaaS 自動化，視覺化拖拽Webhook 非同步觸發
n8n開源可私有部署，節點最豐富JSON 欄位解析與轉換
Zapier整合最多 SaaS 平台Router 條件分支與 Filter

4

技能要求與推薦工具

🛠️ 硬技能

Make.com / n8n 流程設計、Webhook 設定、JSON 處理、REST API 串接、Router 分支邏輯、Error Handling 備案流程。

💡 軟技能

流程分析（發現重複模式）、需求訪談（提取業務痛點）、成本意識（計算自動化 ROI）。

5

實作練習與大型專案

練習 1：第一個自動化流程（2 小時）Make
Gmail 收到標籤郵件 → 篩選「訂單」主旨 → 寫入 Google Sheets → 發送 Slack 通知。
練習 2：跨平台自動化（3 小時）LINE+AI
LINE 收到訊息 → 條件判斷「查詢庫存」→ 查 Google Sheets → 呼叫 ChatGPT 生成回覆 → LINE Bot 回覆。
練習 3（專案 A）：自動商機追蹤與合約生成（5 小時）專案 A
HubSpot 新商機 → 匹配 Sheets 價格 → AI 生成 Google Docs 合約 → 自動寄 Email PDF → 超額通知經理。
練習 4（專案 B）：多平台客服派單與庫存同步（5 小時）專案 B
整合 LINE / Email / 官網表單 → AI 問題分類 → 退換貨查庫存／客訴轉主管／大單轉業務 → 歸檔 Sheets。
