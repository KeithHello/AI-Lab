階段定位與目標

一句話定義：進入 Vibe Coding 領域！擺脫傳統語法死背，用直覺與 AI 協作，快速做出看得見、動得起來的產品原型（MVP）。

你在這個階段的畫像

你已經熟練使用 AI 對話，可能有一個產品點子，但「不會寫程式」卡住了你；或者你會寫一點程式但覺得太慢。這個階段的目標：用 AI 輔助在幾小時內做出一個能互動的原型。

3

知識點與架構

1. Vibe Coding 核心概念與工具矩陣核心

Vibe Coding 心法：先有畫面再寫 Prompt、小步快跑（一次改一個功能）、學會讀程式碼、版本控制是救命繩。

工具類型適合場景
v0.dev零代碼網頁 UI快速原型、Landing Page
bolt.new瀏覽器全棧應用全棧原型、小型工具
Cursor / WindsurfAI IDE修改專案、除錯、輔助開發
Coze / Dify低代碼 Agent 平台搭 Agent Workflow、發布到通訊軟體
2. 基礎網頁與低代碼對照對照

網頁基礎：HTML (骨架), CSS (化妝), JS (動作), 前端 (畫面), 後端 (邏輯), API (溝通), 資料庫 (存資料), 部署 (上線)。

低代碼概念 (Coze/Dify)代碼層概念 (LangChain)
Plugin 插件Tool / Function
Knowledge 知識庫RAG (Indexing + Retrieval)
Workflow 工作流LangGraph StateGraph
Variable 變數State
4

技能要求與推薦工具

🛠️ 硬技能

v0.dev/bolt.new 文字生成原型、Cursor/Windsurf 基本操作、HTML/CSS 閱讀、Git 基礎（init/add/commit）、Vercel 部署、Coze/Dify 搭建。

💡 軟技能

產品感知（從使用者角度思考）、迭代心態（快速改進）、Prompt 進化（從「幫我寫」到「幫我做」）。

5

實作練習項目

練習 1：第一個 Vibe Coding 作品（2 小時）v0.dev
用 v0.dev 生成個人名片網頁，調整文字、顏色並加入技能區塊。
練習 2：Coze Agent 搭建（3 小時）Coze
搭建 AI 日報生成器，搜尋主題資訊並輸出 Markdown 日報。
練習 3：Dify 智能客服（4 小時）Dify
上傳 3-5 份說明文件，設定意圖識別、知識檢索與轉人工記錄。
練習 4：bolt.new 全棧原型（3 小時）bolt.new
生成一個帶資料保存（localStorage）的待辦事項應用。
練習 5：Stage 3 入門準備 — 技術地基（3 小時）🆕5 步地基
1. Python 環境 2. API 理解與呼叫 3. 前端呼叫後端 4. Git 基礎操作 5. Supabase 資料庫體驗。
