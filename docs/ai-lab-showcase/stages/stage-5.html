3

知識點與架構

1. RAG 全流程與優化策略RAG

管道：文件解析 (MinerU/Markitdown) → 語義分塊 (Chunking) → 向量化 (Embedding) → 向量庫 (Chroma/Milvus) → 混合檢索 → Rerank 重排序 → RAGAS 評估。

RAG 效果 80% 取決於分塊與檢索策略！避免切太碎、避免只用向量搜尋失掉關鍵字。
2. Memory 三層架構與 LangGraph 有狀態圖狀態

記憶三層：Working Memory (當前 Context) + Short-term Memory (本次歷史) + Long-term Memory (跨會話摘要)。

LangGraph 核心： State (狀態) + Node (節點) + Edge (條件邊) + Checkpointer (歷史快照與人工介入 Human-in-the-loop)。

3. Multi-Agent 協作、MCP 協議與安全部署架構

協作模式： Supervisor (主副分工)、Decentralized (平等協商)、Hierarchical (層級樹)、Blackboard (共享白板)。框架含 CrewAI, AutoGen, LangGraph, Swarm。

MCP (Model Context Protocol)： 統一工具標準，讓 Client (如 Cursor) 透過標準通訊呼叫 Server 工具。

安全防護： Docker 物理沙箱隔離程式執行，Prompt Injection 護欄防禦惡意注入。
