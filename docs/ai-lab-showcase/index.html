代碼軌與低代碼軌

💻 A 軌｜代碼路線

適合工程背景或希望深入開發的人。重點包含 Python、LangGraph、API、資料庫、Docker、知識庫與多 Agent 系統。

共同終點：兩條路線都要求能做出可測試、可說明、可維護的成果；差別只在使用的工具與技術深度。

練習、專案與 Workflow

Workflow 是什麼？可以把它理解成一張工作步驟圖：資料從哪裡來、經過哪些處理、遇到不同情況走哪條路、最後交付什麼結果。
輸入資料來源
使用者文字、文件、表格、外部 API 或知識庫。
判斷條件節點
辨識需求類型，決定要檢索資料、呼叫工具或轉交人工。
處理AI／工具
整理、分析、生成內容，或串接其他服務完成動作。
驗證測試／人工
使用測試案例確認準確率、例外處理與輸出品質。
輸出成果
產生報告、回覆、通知、資料更新或可展示的應用。

文件中的代表性實作項目

AI 日報生成器

搜尋資料、篩選重點並生成格式化日報。

知識庫客服

從產品文件中搜尋答案，無法回答時交由人工處理。

跨平台自動化

串接郵件、表格、通訊工具與 AI，減少複製貼上。

多角色內容團隊

由研究、撰寫、編輯與審核角色接力完成內容。
